# Assignment submission handoff

## Required links

- **Live demo:** the public Vercel production URL after deployment.

These links have not been created by this export. The existing owner-private prototype is not a replacement for a public submission. Confirm both URLs open without signing in before sending the form.

## GitHub and Vercel

Upload the contents of this project folder, not the outer ZIP, to the repository root. Include app, components, lib, public, scripts, docs, README and configuration files. Exclude node_modules, .next, environment secrets and build output.

From a local checkout, after replacing the URL with your actual repository:

```bash
git init
git add .
git commit -m "Build interactive Fermor homepage"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

Then import the repository into Vercel as a Next.js project. Do not overwrite an existing repository's content or branch without reviewing it first.
